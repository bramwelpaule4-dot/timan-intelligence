# AI integration contract

The AI layer is planned, not connected in this scaffold.

When implemented, it should:
1. Convert a user's question into a structured `AnalysisRequest`.
2. Ask a clarifying question when variables, population, denominator or intended comparison are ambiguous.
3. Select from an allow-list of tested analytical functions.
4. Call the shared analysis service; never invent numerical outputs.
5. Explain only findings returned by the statistical engine.
6. Include methods, assumptions, sample sizes and limitations.
7. Never execute arbitrary Python generated by a language model.
8. Keep provider API keys in deployment secrets or environment variables, never in source code.
